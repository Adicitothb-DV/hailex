# GIT_WORKFLOW.md — Flujo Git y División por Laptops

- `main`: Siempre ejecutable.
- **Laptop 1 (Backend/Datos):** Trabaja exclusivamente en `backend/` y contratos acordados en ramas `feature/backend-*`.
- **Laptop 2 (Frontend/Agronomía):** Trabaja exclusivamente en `frontend/` y `docs/` en ramas `feature/frontend-*`.
- Integración frecuente mediante Pull Requests en GitHub.
