# DATA_SOURCES.md — Fuentes de Datos y Procedencia

1. **NASA POWER Daily Point API** (`https://power.larc.nasa.gov/api/temporal/daily/point`): Parámetros `T2M`, `PRECTOTCORR`, `ALLSKY_SFC_SW_DWN`. Resolución regional; dato observado/asimilado.
2. **INEGI Edafología** (`https://www.inegi.org.mx/temas/edafologia/`): Cartografía regional 1:250,000 o entrada explícita del usuario (`user_input`).
