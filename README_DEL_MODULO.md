# Instrucciones de Uso de `hailex-baseline.zip`

1. Descomprime este archivo en tu carpeta de proyectos (si ya tienes archivos previos en tu laptop, revisa primero con `git status` antes de combinar).
2. Inicializa Git y súbelo a GitHub siguiendo la guía proporcionada por el coordinador.
3. Abre la carpeta `hailex/` en VS Code: Cline detectará automáticamente `.clinerules` y `AGENTS.md`.
